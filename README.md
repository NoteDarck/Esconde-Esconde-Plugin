

## Roleta de funções e seleção de arenas

Antes de cada rodada, os jogadores veem uma roleta visual em uma tela de inventário. A lã verde representa `ESCONDEDOR` e a lã vermelha representa `PEGADOR`; a lã central alterna durante alguns instantes antes de revelar a função sorteada. A interface é bloqueada durante o sorteio e fecha automaticamente antes do jogador ser teleportado para o spawn da sua função.

O comando `/esconde entrar` agora prioriza arenas habilitadas, prontas e que já tenham jogadores aguardando. Entre essas arenas, escolhe a que tem mais jogadores, mantendo as configurações existentes de mínimo, máximo, auto-start, pontos e regras da arena. Se não houver nenhuma arena aguardando com jogadores, ele usa uma arena vazia válida; se só houver partidas em andamento, segue as regras de entrada como espectador.
